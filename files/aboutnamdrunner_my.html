Instructions

NAMDrunner requires 4 input files:

  • Coordinate File:
A file containing initial coordinates;
in demo's min/ and md/ folders there are examples of step2_solvator.pdb and namd_out_whole_min.coor files, respectively;
(extension can be anything, but the file must be in .pdb format)

  • PSF file:
Protein Structure File in .xplor format
step2_solvator.xplor.psf - an example in min/ and md/ demo folders

  • Parameter file (.zip):
A single .zip archive which reflect the structure of the toppar directory used in Input NAMD Script E.g., if the "parameters" section in the input script looks like
--------------------------------------------
parameters toppar/par_all36_prot_for_namd.prm
parameters toppar/toppar_water_ions_for_namd.str
---------------------------------------------
than a .zip parameter file should have the following structure:
--------------------------------------------
toppar/
toppar/par_all36_prot_for_namd.prm
toppar/toppar_water_ions_for_namd.str
--------------------------------------------

  • Input NAMD script:
Samples of minimization (namd_prot_min.inp) and MD run (namd_prot_md.inp) input scripts are, respectively, in min/ and md/ folders
