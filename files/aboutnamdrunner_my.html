Instructions

NAMDrunner minimally requires 4 input files:

  • NAMD configuration script:
Here are, respectively, examples of minimization, MD run scripts, and also an example of a script specifying minimization with a consequtive MD equilobration run: namd_prot_min.inp, namd_prot_md.inp, minimizeandequilibrate.inp

  • PSF file:
Protein Structure File in .xplor format
Examples for MD and Minimization runs, respectively, are provided: step2_solvator.xplor.psf and step2_solvator_min.xplor.psf

  • Coordinate File:
A file containing initial coordinates;
in demo's min/ and md/ folders there are examples of step2_solvator.pdb and namd_out_whole_min.coor files, respectively;
(extension can be anything, but the file must be in .pdb format)

  • Parameter file (.zip):
A single .zip archive which reflect the structure of the toppar directory used in Input NAMD Script E.g., if the "parameters" section in the input script looks like
--------------------------------------------
parameters toppar/par_all36_prot_for_namd.prm
parameters toppar/toppar_water_ions_for_namd.str
---------------------------------------------
than a .zip parameter file should have the following structure:
--------------------------------------------
toppar/
toppar/par_all36_prot_for_namd.prm
toppar/toppar_water_ions_for_namd.str
--------------------------------------------
See example toppar.zip

When uploading files manually, user can also upload an arbitrary number of additional files specified in NAMD configuration script, by using 'Number of additional files to upload' field. These files may be exemplified by: binary velocity/coordinate files, velocity file, .xsc (cell dimensions) file, .pdb files specifying constraints etc.

How to upload files

NAMD configuration script is uploaded separately, using 'Input NAMD script' field.
There are 2 options for uploading all other files (PSF, coordinates, parameters and any additional files):

  • manually,
  • by uploading a single .zip archive which contains all needed files.
